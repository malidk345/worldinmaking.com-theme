## 2025-02-23 - Prevent UI Thread Blocking in Resize Listeners
**Learning:** Found an opportunity to improve frontend performance by optimizing the `useBreakpoint` hook which listens to high-frequency `window.resize` events. Modifying state repeatedly during these events without bailout mechanisms or passive event listeners can block the main UI thread.
**Action:** When working with resize or scroll event listeners, always attach `{ passive: true }` if `preventDefault()` is not needed. Additionally, use functional state updates with a bailout check (e.g., returning `prev` if equality holds) to avoid unnecessary React re-renders. Applied this optimization to `src/hooks/useBreakpoint.ts`.
