## 2024-05-28 - Extract static feature processing out of useFeatureOwnership hook
**Learning:** Found an instance in `src/hooks/useFeatureOwnership.tsx` where a static object `FEATURE_DATA` was being processed with `Object.entries().reduce(...)` to generate a `features` object *on every single render* of any component using the `useFeatureOwnership` hook. Furthermore, the `useMemo` hook had a missing dependency for `features`, preventing it from running when `features` (which changed reference on every render) actually changed.
**Action:** Always extract static data processing (like reducing/mapping hardcoded constants) out of React hooks to the module level. This prevents expensive object allocations and function calls on every render, and keeps references stable.
